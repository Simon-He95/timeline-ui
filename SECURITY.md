# Security Policy

## Supported versions

Security fixes are applied to the latest published minor release.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private
vulnerability reporting form:

https://github.com/Simon-He95/timeline-ui/security/advisories/new

Include:

- affected version
- a minimal reproduction
- expected and actual behavior
- any relevant browser or framework versions

The maintainer will acknowledge the report and coordinate disclosure after the
issue is understood and a fix is available. Good-faith research is welcome.
